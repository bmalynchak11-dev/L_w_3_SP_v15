# Стартовий проєкт SP-LAB03

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace; середовище привілейоване, тож простори імен доступні) або локально на Linux: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`.
2. Визначте свою задачу за номером варіанта: задача = `(номер - 1) // 3 + 1`. Реалізуйте її у файлі `variants/lab_NN.py` за карткою.
3. Запускайте відкриті тести своєї задачі: `pytest tests/test_lab_NN.py` (NN з двома цифрами). Права root не потрібні.
4. Тести, яким потрібні простори імен користувача або cgroups v2, а середовище їх не дозволяє, пропускаються з поясненням (`SKIPPED`). Повний дослід виконайте на сервері коледжу або у віртуальній машині (розділ 3 завдання).
5. Змінюйте лише свій файл у `variants/` (і за бажанням `tests/test_my.py`).
